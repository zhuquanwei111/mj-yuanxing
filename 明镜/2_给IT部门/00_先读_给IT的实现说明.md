## 一、总览

**明镜 = 直播公会的 AI 工作平台。纯手机 APP 形态——一台手机，12 种角色选身份进入，51 屏。**

```
平台（我们自己运营）：管入驻、管开通、管公会成长、管用量和收钱
   └─ 公会（ToB）：10 种角色各一套工作台——老板/总监/组长/运营/经纪人/培训/妆造/编导/剪辑/财务
        └─ 主播（ToC）：私人助理，五 Tab
   ＋ AI 引擎页（P96，无角色可达）：能力/工具箱/调用链/对标——给投资人和 IT 的架构页
```

- **三端**：ToB 公会端（10 角色）＋ ToC 主播端 ＋ 平台端。
- **形态**：单文件 HTML、零依赖、双击可点；每屏手机壳内单列流。
- **数据口径冻结**：公会月流水 1,560 万声浪（折流水 ¥156 万）→ 平台应付 ¥18.7 万；收入三块（服务费 3.6＋AI 加价 1.8＋会员分账 0.9＝6.3 万）；主播分成 40/42%；保底 ¥0.8 万演示。

## 三、AI 能力层（31 项能力＋工具箱十件＋调用链）

> 完整版见 `_规划_AI能力层.md`。本节是 IT 视角的精炼。

### 3.1 四类能力（31 项）

| 类 | 商业语言 | 能力项 |
|---|---|---|
| **感知**（7） | AI 帮你盯 | 主播数据 / 全局大盘 / 异常信号 / 业务事件 / 沟通情绪 / 排期分布 / 行业基准 |
| **认知**（10） | AI 帮你判断 | 流失归因 / 撞档检测 / 档位判断 / 对账差异 / 结算预审 / 转化漏斗 / 经营建议 / 基准解读 / 意图理解 / 薄弱定位 |
| **生成**（7） | AI 帮你写 | 直播规划 / 复盘 / 脚本选题 / 邀约话术 / 差异解释 / 经营周报 / 助理回复 |
| **执行**（7） | AI 帮你办 | 执行卡 / 通知下发 / 任务下达 / 状态流转 / 回执回写 / 数据下钻 / 月报导出 |

**两容器规则**：🤖 自动卡（浅灰底＋黑左肩，只读可展开）；✍️ 草稿双栏（左草稿右拍板：采纳/修改/不用）；🖐 人操作。**铁律：AI 永不静默改状态——改状态的动作必须人点按钮。**

### 3.3 调用链

```
人（点按钮 / 问助理 / 等事件）
  → 明镜界面（50 屏，权限过滤）
  → 明镜助理（意图匹配，选能力）
  → AI 能力层（感知→认知→生成→执行）
  → 业务工具（十件）
  → 结果（草稿/卡片/提醒/状态）
  → 人拍板（采纳/派人/确认）→ 状态变更 → 事件回写（P90 系统卡/沟通记录）
```

### 3.4 Harness 对标（一句话版）

与 Claude Code 同构：模型不动，工具箱从文件系统换成公会业务十件。差异：Claude Code 靠人发起（你问它答）；**明镜七成场景事件自动发起——AI 值守，有事叫你，你拍板**。工具是垂直窄域函数，出错面小、审批点清晰。

## 四、数据架构（六组 29 张表，完整字段见 `_规划_数据与架构.md`）

| 组 | 表数 | 内容 |
|---|---|---|
| 租户与组织 | 4 | guild / staff / role_config / dept_group |
| 主播主数据 | 3 | anchor 主档（参照行业典型 56 字段主档裁剪）/ 生命周期 / 标签 |
| 数据采集 | 4 | 日播明细（导入一等公民）/ 快照 / 素材 / 用量 |
| 招募签约 | 4 | 线索 / 面试 / 签约 / 交接 |
| 协作单据 | 8 | 规划 / 复盘 / 妆造单 / 调试单 / 服装 / 工单 / 脚本 / 成片 |
| 运营产物与财务消息 | 6 | 沟通记录 / 通知 / 事件 / 待办 / 绩效 / 报表 |

**三条关系纪律**：① 每张业务表必带 `guild_id`；② 主数据与单据分离（档案改字段，单据留痕）；③ 明细与快照分离（官方口径算完落快照，页面读快照）。**AI 产物落库三态**：草稿→已改定→已生效，永远记录「AI 写了什么 / 人改了什么」。

**多租户双保险（已定，回填原待定项 #5）**：共享库＋行级隔离——第一道「进门验」（ORM 强制注入 guild_id）＋第二道「门锁验」（数据库 RLS 策略），写入时即隔离。
