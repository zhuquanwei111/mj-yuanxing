## 二、全局规矩（每一页都必须遵守）

1. **每页左上角标三行小字**：页面名 · 谁在用 · 一句话干什么（部分页加第四行「价值」灰字）。看不懂的页面一律不做。
2. **三把尺子**（每页自检，违一即返工）：像**真APP**；**零真实公司/零自夸**；**零演示字样**。
3. **AI 分层图例**（全原型统一）：🖐 **人操作**｜🤖 **AI 自动**｜✍️ **AI 草稿+人拍板**。凡 AI 插手处标「AI 做了什么 / 人拍什么板」。**铁律：AI 永不静默改状态。**
4. **形态**：纯手机 APP（原型即手机壳单列流）；视觉 v4 token（黑白灰＋近黑 #111827 唯一强调色，规范见 `_规划_设计规范v5.md`）。
5. **单文件 HTML、零依赖、双击能点**，页面间真实跳转，按钮全是动词。
6. 示例数据：公会「星曜传媒」，主播小雨、阿哲、喵喵等，全行业通用虚构。
7. **中文不用单引号**（HTML 内）。
8. **导航=工作流**：底部 Tab 按角色分（4-5 格）；详情子页（P41D/P30D）由列表点名进入，不进导航。
9. **AI 两容器**：🤖 浅底只读卡 / ✍️ 草稿双栏（左草稿右拍板）。

## 四、关键动线（必须一路点通）

1. **入驻线**：P00「申请入驻」→ P10 → P01 审核时间线 → P11 向导 → P13
2. **运营的一天**：P20 → P21（快捷三件）→ P22（生命周期条）→ P23 三段式 → P24
3. **协作线**：P22 转交 → P50 转交单（黄条）→ P51 详情 → 回执 → P20/P25
4. **新人线**：P31 话术 → P32 三步 → P40/P41 → 结业 → P25 → P20
5. **招人线**：P31 录线索/话术 → 标已签约 → P30 漏斗
6. **主播的一天**：P80 → P81 → P82 → P83 → P84
7. **组织线**：P93 决策建议采纳 → P94 组长卡 → 标记完成 → P93 翻绿；P95 调人 → 全站聚合实时变
8. **沟通线**：系统事件（结业/预警/账单）→ P90 系统卡 → P92 消息中心
