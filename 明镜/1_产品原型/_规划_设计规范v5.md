# 第一部分 · 设计规范 v5

## 1. 色彩系统

### 1.1 中性色（骨架，90% 的画面）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | #FAFAFA | 屏幕底 |
| `--card` | #FFFFFF | 卡面 |
| `--ink` | #111827 | 主文字/主数字/主按钮底（兼品牌色） |
| `--ink2` | #6B7280 | 次要文字 |
| `--ink3` | #9CA3AF | 辅助文字/占位/微字 |
| `--line` | #F0F0F0 | 卡边框/分隔线 |
| `--line2` | #F3F4F6 | 浅底块（AI 卡/次按钮/进度槽） |
| `--禁用` | #D1D5DB | 禁用文字/不可点 |

### 1.2 品牌与功能色

| Token | 值 | 规则 |
|---|---|---|
| **品牌/强调** | #111827（近黑） | 唯一强调色。主按钮底、选中态底、进度条、图表柱、执行卡左肩 |
| **成功** | 字 #3F6212 / 底 #F7FEE7 | 仅用于「已完成/已通过/已送达」语义 |
| **危险** | 字 #B91C1C / 底 #FEF2F2 / 左条 #B91C1C | 仅用于「异常/需补考/差异」语义 |
| **警示** | 左条/底 #D9A441（黄） | 仅用于「待处理/需关注」语义，用左条不整块浸染 |
| **环比** | ↑ #3F6212 / ↓ #B91C1C | 透明底，只变字色（v4 已定，不再用绿/红底块） |

### 1.3 三条铁律

1. **一屏最多一个强调面**：黑色实底块（选中 Tab/主按钮/当前生命周期段）全屏 ≤3 处；
2. **彩色只表达状态，不表达装饰**：没有语义的元素一律灰阶；
3. **图标单色**：全部继承文字色，emoji 仅限 🤖/✍️/🖐 三个 AI 图例。

## 2. 字体排印

### 2.1 字号阶梯（8 档，超出即错）

| 档 | 字号/字重 | 用途 |
|---|---|---|
| D1 | 30px / 650 / tabular-nums / 字距 -0.02em | KPI 大数字（配 small 单位 13px/600） |
| D2 | 17px / 600 | 页题（ph-t） |
| D3 | 16px / 640 | 顶栏标题（mt） |
| D4 | 13px / 640 | 卡题（ct）· 对话昵称 |
| D5 | 12.5px / 640 | 列表主文字 · 正文强调 |
| D6 | 12px / 400 / 行高 1.6-1.7 | 正文/辅助（kpi label、说明行） |
| D7 | 11px / 400 | 徽章/微说明/灰注记 |
| D8 | 10.5px / 400-620 | 最小档（scopechip/时间戳） |

### 2.2 排印规则

1. **数字一律 `tabular-nums`**（所有会变化的数字：金额/进度/时间戳）；
2. 中文字重只用 400/620/640/650 四档，**禁用 300（发虚）与 700+（发黑）**；
3. 大数字永远配一行 ink3 的 label——数字自己会说话，label 负责单位与口径；
4. 正文行高 1.6-1.7；标题行高 1.3。

## 3. 间距系统（8pt 网格）

| Token | 值 | 用途 |
|---|---|---|
| S1 | 4px | 徽章间/图标-文字微距 |
| S2 | 8px | 卡内元素组间距 |
| S3 | 12px | 卡与卡的垂直间距（全站统一卡距） |
| S4 | 16px | 屏左右边距 · 卡内边距（紧凑卡 14px 允许） |
| S5 | 20px | 区块间（头/内容/底） |
| S6 | 28px | 大区块分隔/弹层内组间距 |
| S7 | 40px | 屏级留白（空态上 padding） |

规则：卡内边距 16px（紧凑卡 14）；**卡与卡垂直间距一律 12px**——现状 11/13/14 混用是漂移主因之一；区块间 20px，两卡成组靠留白不靠线。

## 4. 组件规范（结构＋样式＋状态）

### 4.1 卡片 `.card`
- 结构：标题行（ct：D4 主文＋m 微字 ink3）→ 内容 → 动作区（sact/tact 右对齐或均分）
- 样式：白底 / 1px `--line` / 圆角 14 / **无阴影** / 内距 16
- 状态：默认 ｜ 强调（边框转 `--ink`，用于证书/关键卡）｜ 警示（左 3px 黄条 `--D9A441`）｜ 危险（左 3px 红＋红浸底，仅预警/差异）

### 4.2 按钮 `.btn`
| 变体 | 样式 | 语义 |
|---|---|---|
| `p` 主 | 黑底 #111827 白字，圆角 10，高 36，padding 0 18px | 每屏唯一主动作 |
| `g` 次 | 白底 1px line 墨字 | 次动作（可多个） |
| `q` 弱 | 浅灰底 #F3F4F6 灰字 | 弱动作/取消 |
| `d` 危 | 白底红字红边 | 驳回/停用 |
- 状态：默认 / `:active` 缩放 0.97（0.1s ease-out）/ 禁用（灰底灰字）
- 规则：**一屏一个 `p`**；按钮文案必须是动词（「生成规划」非「规划功能」）。

### 4.3 列表行 `.mrow`
- 结构：头像（34-38px 灰阶）＋两行文本（D5 主＋D7 辅）＋徽章＋动作按钮；可整行点击的加右滑箭头
- 状态：默认 / 风险（左 3px 红条＋红浸底）/ 关注（左 3px 黄条）/ 已完成（文本 ink3＋可划线）
- 分隔：**卡片化，无行线**；行间距 8px

### 4.4 徽章 `.badge`
- 五态：`ok` 灰绿底 / `b` 浅灰底墨字（进行中）/ `line` 灰字（中性）/ `warn·dg` 红底 / `warn-line` 黄条
- 样式：圆角 99、10.5-11px、600、padding 2.5px 8px；**一屏徽章 ≤5 色**

### 4.5 表单
- 输入：白底 / 1px line / 圆角 10 / 高 36 / D6；`focus` 边框转 `--ink`（0.15s）
- 标签：D7 ink3，在输入上方 4px
- 长表单：按语义分组，组间 S6=28px＋组标题 D7；**超 6 字段必须分步**（参考 P23 段1）

### 4.6 图表
- 柱状：#111827 实色、圆角顶 3px、最小高 3px；对比柱/基准线 `--line`；零值 `--line2`
- 数值：全部 tabular；明细 chips（D8）在图下
- 规则：图表只有黑/灰两色＋基准线，**不上彩色**

### 4.7 对话流
- 我：右对齐、黑底白字、圆角 12（右下 3）
- AI/对方：左对齐、白底 1px line（AI 专属：浅灰底 `--line2`＋🤖 前缀）
- 执行卡：白底＋**3px 黑左肩**＋右箭头，独立于气泡下方
- 时间戳：D8 ink3

### 4.8 Tab（底部导航）
- 5 格上限：icon＋D8 文字；选中：墨字＋icon 填充；未选：ink3
- 页内 chips（`fchip`）：白底 1px line 灰字；**选中一律黑底白字**（全站唯一选中态，禁用描边选中）

### 4.9 顶栏 `.mhead` / 弹层
- 顶栏：白底底线；返回‹（40×40 命中区）/标题 D3/消息铃＋红点角标/角色 chip（浅灰底）
- 弹层：底部滑出、白底、圆角顶 16、内距 20；遮罩 rgba(17,24,39,.4)；标题 D4＋说明 D7＋表单组＋底部双按钮（主/取消）

### 4.10 空态 `emptyBox`
- 结构：灰图标位＋一句话结论＋一句去向＋按钮；**每个列表页必须有空态**（不能白屏）

## 5. 布局模式

1. **手机壳**：`.mshell`＝顶栏（56px）＋内容滚动区＋底部 Tab（56px）；内容单列、左右 16px；
2. **页面骨架**：ph 三行头（页题/谁在用/干什么/价值行）→ 内容（单列 12px 卡距）；
3. **列表-详情**：列表点入详情，返回按钮 `backFor()` 来源优先（从哪来回哪去）；详情页不进底部导航；
4. **底部 Tab 分角色**（每角色 4-5 个）；AI「助理」永远最后一个 Tab；
5. **桌面后台（预留）**：左侧导航 200px＋顶栏＋内容区——当前原型以手机壳为准，桌面形态留待真机。

## 6. 动效规范

| 场景 | 参数 | 说明 |
|---|---|---|
| 页面转场 | `.pagein` 0.18s ease-out：opacity 0→1＋translateY 6px→0 | 仅页面切换播，同页状态变化不重播 |
| 按压反馈 | scale 0.97，0.1s ease-out | 所有可点元素 |
| 弹层 | 滑出 0.22s ease-out＋遮罩 0.15s fade | 底部滑入 |
| 徽章/勾选/开关 | 0.15s ease-out | 颜色与形状过渡 |
| toast | 2.6s；出现 0.2s 淡入＋上移 | 一次性反馈 |
| 生成过程 | workline 逐条出现，每条 720ms | P23 段2 专属节奏 |
| 禁忌 | 不动 layout 属性（width/height/top）；不加循环动画；数字不滚动 | 性能与克制 |

## 7. AI 元素规范（AI 视觉语言——全站一致）

| 元素 | 规范 |
|---|---|
| 🤖 自动卡 `aicard` | 浅灰底 `--line2`＋1px line＋**3px 黑左肩**＋🤖 徽章头（aih：D4＋m 微字）＋aib 行（状态点 ok/warn＋一句话） |
| AI 分工行 `ailine` | 每处 AI 插手必标：「🤖 AI 做了什么 ｜ 🖐 人拍什么板」D7 ink3 |
| ✍️ 草稿双栏 `draftbox` | 左＝草稿正文（白底线框）；右＝固定三动作「采纳/修改/不用」；采纳后翻徽章 |
| 生成过程 `workline` | 灰底圆角行＋🤖 前缀，逐条 720ms 出现，末条「草稿已就绪」 |
| 执行卡 `actcard` | 白底＋3px 黑左肩＋「动作词 ›」，点开带参直达 |
| 步骤条 `p23steps` | 三段：done 白底描边 / cur 黑底白字 / todo 浅灰 |
| 铁律 | 🤖=只读结果；✍️=草稿等拍板；🖐=人操作。**AI 永不静默改状态** |

# 第三部分 · 优化方案（怎么改 / 改完什么效果）

## S1 表格卡片化/极简化（6 处，工作量大头）
- **怎么改**：P03 排行/P16 用量/P40 名单→改 `.mrow` 卡片行（头像+名+badge+数值）；P42 矩阵/P62 成片→保留表格但重绘（去表头底色、行线只留 `--line` 极细分隔、数字 tabular、单元徽章化）；P03 公告行→doneitem 化。
- **改完效果**：6 屏与 P20 卡片语言统一，视觉噪音下降一档；老式「后台表格感」清零。

## S2 控件统一（三套选中态归一）
- **怎么改**：ptab/p22tab 全部对齐 fchip 规范（选中=黑底白字圆角 10）；P31 三动作对齐 draftbox（p/g/q 固定搭配）；P12 活格选中态同步。
- **改完效果**：全站任何页的「选中」长得一样——用户零学习成本。

## S3 间距 token 化（一条命令级修复）
- **怎么改**：全局把卡片 margin 11/13/14px 统一 12px；卡内边距统一 16（紧凑 14）；区块间 20px；改 CSS 变量即可（`--gap:12px`）。
- **改完效果**：呼吸感全站一致——这是「漂移感」的最大来源，一次修复收益最大。
