## v3 相对 v2 加了什么

| 加了什么 | 治什么 |
|---|---|
| **§3.0 改成"同一句话的六种画法"**（字段／长度／明度／斜率／时间／位置，带 ASCII 对照） | v2 的三个示例全是"字段标签"，把模型教成了只会排格子 |

| **主通道唯一**：每方向 1–2 个主通道，同批组合不得重复；须声明"掉多少／谁先做／风险几档"各用什么通道 | 三个方向都是格子 |

| **缩略图测试**：缩到约 100px 宽并排，还必须认出是不同的图 | "格子内部换花样"也能过关的漏洞 |
| **配额改成**：深底 ≥1、零彩色 ≥1、**量类通道为主 ≥1** | 默认审美趋同 |
| **八项交付前自检**（缩略图／删 CSS／数汉字／比色板／比通道／swap／signature／配额） | 不合格方案在交付前暴露 |

## 发送前必读：让它"忘记前几轮"

1. **新开对话**，不要在旧对话里继续（上下文里有旧设计，它会不自觉复用）。
2. **不要附带任何旧产出**：不上传旧截图/HTML，不粘贴旧方向卡或对比页。
3. **不要提前几轮做过什么**——尤其别说"上次有个泳道的不错"。一句话就会把旧结构带回来。
   （好模式要复用，是**我们落地时**用，见 `../03_好设计模式库.md`；别写进给模型的提示词。）
4. 若它自己说"我看到项目里有 gpt-d1…"，告诉它**不要看**，只按任务书从零做。
