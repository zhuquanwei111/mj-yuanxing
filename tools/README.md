# 本地预览服务（解决 file:// 被浏览器安全策略拦下）

## 问题

验收用的内置浏览器只允许 `http:` / `https:` / `about:blank`，`file:` 一律拒绝导航。
所以直接用 `file:///D:/.../明镜产品原型.html` 打不开，也就无法截图、点击、看渲染 —— 上一轮审查只能靠读源码推断，就是这个原因。

## 解决

把文件夹用本机 HTTP 挂出来再打开，路径不变、内容不变。

```bash
node tools/serve-local.mjs                    # 启动默认预览（根目录 = 国庆后的原型）
node tools/serve-local.mjs --open             # 启动并自动用默认浏览器打开原型页
node tools/serve-local.mjs --port 9000        # 换端口（默认 8788，占用时自动 +1）
node tools/serve-local.mjs "4_风格选型/kimi-风格方案/kimi-d1-战报.html"   # 指定任意页面
```

Windows 下可直接双击 `tools/start-preview.cmd`。

启动后地址（端口以启动输出为准）：

- 目录首页：<http://127.0.0.1:8788/>
- 产品原型：<http://127.0.0.1:8788/明镜/1_产品原型/明镜产品原型.html>
- 深链可用，例如 `...#P13`（老板经营大盘）、`#P14`（主播资产总表）、`#P20`（运营待办）

## 特性与边界

- 只绑定 `127.0.0.1`，不对局域网/外网开放；零依赖，只用 Node 自带模块。
- 响应带 `cache-control: no-store`，改完 HTML 刷新即可看到，不会拿到旧缓存。
- 当前端口/根目录/进程号写在 `tools/.preview-state.json`，供后续会话或脚本读取。
- `favicon.ico` 返回 204，避免控制台刷 404 噪音。
- `tools/` 目录已被仓库 `.gitignore` 忽略，不会污染交付内容。

## 停止服务

前台运行时 `Ctrl+C`；后台运行时结束对应 Node 进程即可（见 `tools/.preview-state.json` 的 `pid`）。
