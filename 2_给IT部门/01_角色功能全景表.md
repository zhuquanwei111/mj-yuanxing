## 一、产品一层（给谁的什么）

```
平台（我们自己运营）：管入驻、管开通、管用量和收钱
   └─ 公会（ToB，电脑后台）：老板看大盘，员工各干各的活
        └─ 主播（ToC，手机）：私人助理，四件事
```

## 二、全局规矩（每一页都必须遵守）

1. **每页左上角标三行小字**：页面名 · 谁在用 · 一句话干什么。看不懂的页面一律不做。
2. **三把尺子**（每页自检，违一即返工）：
   - 像**真APP**：有菜单、有表格、有按钮、点了有反应，不是大字报不是文档；
   - **零点悦**：不出现任何真实公司名、真实人数、内部表名，数据全部用行业典型虚构值；
   - **零AI痕迹**：命名、文案、图标像正经产品经理出的货，不自夸AI、不写"演示数据"之类说明字。
3. **AI分层图例**（全原型统一）：
   - 🖐 **人操作**：填表、审批、确认、拍板——人点按钮才发生；
   - 🤖 **AI自动**：预警、汇总、提醒——后台跑完人只看结果；
   - ✍️ **AI草稿+人拍板**：规划、复盘、话术、脚本——AI出初稿，人改定才生效。页面上凡AI插手处，标一行"AI做了什么 / 人拍什么板"。
4. **设备形态**：公会端=电脑后台（左侧导航+顶栏+内容区，信息密度参考钉钉/飞书管理后台）；主播端=手机界面（页面内嵌手机框）。
5. **单文件HTML、零依赖、双击能点**，页面间真实跳转，**每个按钮都是动作词**（"去复盘"，不是"复盘功能"）。
6. 示例数据：公会名用「星曜传媒」，主播用小雨、阿哲、喵喵等常见昵称，全行业通用。
7. 技术坑：HTML内的中文一律不用单引号。
8. **导航分组对齐真实工作，不对齐官方后台**：一级导航=工作台/主播/内容/协作/结算/设置。官方公会后台已有的"数据报表/任务管理/活动报名"不占一级位置——官方已有的功能明镜只做引用、不重画，公告类降级为顶栏通知。
9. **画页执行标准**：界面规矩10条见 `_调研_公会后台与界面形态.md` 第三部分（骨架1920×1080左导航+64px顶栏、工作台信息序=待办流→指标卡→图表、列表页四件套、详情页三位一体、预警三层呈现、状态=颜色+文字、指标卡≤4个数、AI两容器🤖/✍️、主播端5Tab单列流），画页时逐条对照。

## 四、关键动线（必须能在原型里一路点通）

1. **入驻线**：P10申请 → P01平台审核 → P11开通向导 → P13老板大盘
2. **运营的一天**：P20今天（早班消化昨晚夜场） → P21主播列表 → P22详情 → P23生成规划发主播 → P24复盘
3. **交接线**：P22运营"转妆造" → P51妆造接单 → 完成 → 自动回P20
4. **新人线**：P32签约 → P41培训任务 → P20运营接手
5. **主播的一天（手机）**：P80今天 → P81规划 → （直播）→ P82复盘 → P83问一句
6. **ToB↔ToC衔接**：公会导入主播 → 主播收到邀请 → P85激活 → 公会派的活出现在P80 → 主播日常独立用 → P85可升级会员（未签公会的主播也能自己注册用基础功能）

## 五、AI功能点清单（每个AI动作的实现思路一句话，详细展开留给《给IT的实现说明》）

| AI功能 | 在哪页 | 干什么 | 实现思路一句话 |
|---|---|---|---|
| 数据异常预警 | P13/P20/P21 | 谁的数据掉了自动说 | 规则+模型双跑：规则先筛，模型写原因 |
| 平台任务进度自动算 | P13/P70 | 拉新/活跃/流水进度条+差多少达标 | 官方口径（活跃=10有效天/20小时）做成自动计算——官方要人肉Excel，这是第一卖点 |
| 直播规划生成 | P23/P81 | 单场到完整阶段方案 | 主播档案+近期数据喂给大模型，出结构化草稿（时段/时长/画面/话术/目标） |
| 复盘生成 | P24/P82 | 三句话复盘 | 昨晚数据→固定框架生成，人可改 |
| 问一句 | P83 | 话术/问题随时答 | 知识库检索+大模型，行业知识+公会自己资料分级 |
| 流失预警 | P15/P33 | 谁要跑、为什么、派谁 | 数据信号+沟通记录，输出原因（五类）和建议动作 |

## 六、我自己拍板的事（有异议随时推翻，说了就改）

1. 公会端做电脑后台，主播端做手机界面（原型即所见；IT可再选小程序/APP承载，不影响本表）。
2. 一期把「运营」这条线画到最深（P20-P24），因为最通用、最痛；其余角色画齐、深度递减。
3. 计费不做复杂页面：平台方看板里放"用量与套餐"一处即可。
4. 商业口径跟《商业计划书》一致（公会服务费 + 主播会员100元/月），原型只体现入口，不展开价格。
5. 主播数据来源：一期按"公会后台导出/手动同步"设计；开放接口写进实现说明，当二期。
