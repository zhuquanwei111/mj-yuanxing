# DESIGN.md｜明镜 Stitch 共用样式依据

适用于明镜移动端多角色原型。本文件同步当前用户明确配色，不宣称已定企业品牌。用户提供的Stitch基座链接：<https://stitch.withgoogle.com/projects/16903879618660142322>。当前只是导入参考，未在Stitch上传或生成。

## 画布、字体与布局

- Stitch目标画布 390×884；竖向滚动并尊重安全区。原参考图尺寸可能为1552×2592、1584×2640或其他，真实像素记在 IMAGE-INDEX.csv；原图不可裁切或覆盖。
- 字体优先 Noto Sans SC，回退 `-apple-system/BlinkMacSystemFont/PingFang SC/Microsoft YaHei/sans-serif`；不用 Inter/衬线字体。标题20–24px，正文14–16px，辅助12px，以字重/留白分层。
- 8px间距节奏，触控目标≥44px；移动优先360–430px，不横向溢出。各角色导航按各自源母版；同角色跨页图形/顺序/标签/选中态一致。详见 ICON-USAGE-INDEX.md。

## 当前颜色变量与语义

| Token | 用途 |
|---|---|
| `#FAF5F1` | 暖白画布 |
| `#FFFFFF` | 白色表面、导航、浮层 |
| `#F4F0ED` | 次级区域、低强调控件 |
| `#EBE5E0` | 安静边界/分隔 |
| `#282838` | 标题、正文、数字及允许的中性操作文字/图标；不可作为实心黑色按钮底色 |
| `#686260` | 说明/标签/元信息与未选中中性文字 |
| `#F88440` | 暖橙品牌操作、选中导航/链接、关键进度 |
| `#FCF4EC` | 预览/提醒/选中浅底；节制使用 |
| `#D96A31` | 橙色操作按下/强调交互态 |
| `#EF4444` / `#BA1A1A` | 风险/错误；配文字/图标和浅红底，不整卡染色 |
| 琥珀语义色 | 待处理/提醒；配状态文案与图标 |
| 绿色语义色 | 在播/正常/已完成；配状态文案与图标 |
| 蓝色语义色 | 培训/信息提示；不是品牌色 |
| 中性灰 | 已下播/普通历史 |

- 主操作用橙底白字；次操作可以中性深色字。选中Tab可深色加粗+暖橙下划线；交互文字按动作/状态分配颜色，不将按钮文字和按钮底色规则混为一谈。禁用态仍可读并与可点态区分。
- 暖橙节制用于主要动作/选中/进度；允许同色系浅底/描边，但不把每个图标、卡片都染橙。禁止紫、霓虹、青色/蓝绿色作为品牌方向或竞争强调色。
- 风险红、待处理琥珀、在播/完成绿、培训/信息蓝、普通历史灰是语义色，不替代暖橙品牌色。颜色必须有相应文字/图标。

## 组件与容器

- 平面内容为主、必要卡片为辅；默认最多一级主要可见容器。名单/任务/成员用连续行；档案/账单/规则用分节字段行；对话用连续流；状态/风险局部提示条。
- 容器须表达独立对象或操作；能用留白/对齐/细分隔说明的，不再嵌套圆角盒。阴影仅用于真实浮层/弹窗；边框、背景、圆角克制且同角色共用。
- 输入标签在上、验证信息在下；必填/禁用条件贴近字段/按钮。一次只突出一个主要动作，次动作不伪装成禁用。
- 不加设备框、仿系统状态栏、Home条、水印或无源品牌标识。

## 业务与状态约束

- 图片是视觉参考，不是交互证据。点击结果、字段来源、页面路由以对应 FLOW.md/ROUTE-MAP.md 与源/正式映射为准。
- 本地演示必须明确本地范围；不暗示真实后台送达、对方已读、跨账号持久化、平台结算确认或真实付款。
- 同一计划/复盘/风险/消息/任务跨页字段与身份键保持一致；来源未定义的值不补造，待确认项参见“待确认与缺口.md”。
