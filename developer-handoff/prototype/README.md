# Stitch 逐页原型样本

本目录收录 2026-10-19 最新合格页面导出中的 36 个 HTML，按 manifest 与源文件逐项 SHA256 核对。文件来自两个来源：上一合格导出原样复制、当前 Stitch 屏幕原样下载；未改动 HTML/CSS/JS。manifest 保留每页源 screen ID、画布元数据、原文件名与哈希。

逐页文件可以单独打开；没有统一壳、跨页面路由或端到端交互验收。每个 HTML 声明的 CDN/Google Fonts/Material Symbols 资源需要网络才能完整呈现。全量候选中未通过或未验收的页面见 `../provenance/excluded-prototype-pages.csv`。
