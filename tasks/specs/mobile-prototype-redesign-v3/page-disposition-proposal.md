# 页面库存取舍决策（V3）

这是经用户批准后用于 V3 实施的页面去向决策。旧矩阵只说明现状，不能要求未来保留相同数量。索引可作为 QA/历史深链别名，即使产品中已合并对应视图。

**已定的架构取舍：** 不新增常驻一级业务模块，先补齐现有页面的空/失败/处理中/完成状态；P21 动态为名单的同级收件箱视图；P22 对象详情保持统一上下文；P23 计划与 P24 复盘保留两个独立任务页，但共享对象头、状态语法和来源返回；P30D 保留为单对象跟进详情，P33 保留关怀工作流并能升级到 P15；P60 内容与 P62 剪辑因角色和生命周期不同继续独立，复用任务行；P83/AI 共用助理模式；P84 进入主播 MY；P90 群会话、P91 单聊与 P92 通知/会话列表属于同一消息中心家族，旧 hash 继续指向对应视图；P94 组务与 P95 全组织管理保留不同任务边界。

## 新增项判断

当前执行决定是先把空、失败、权限不足、处理中、成功/撤销状态补进已有任务页，不新增常驻一级业务模块。若浏览器任务测试证明跨角色用户无法发现风险/任务/消息，再检验是否需要统一收件箱，并与 P20、P25、P92 对照后决定。新增入口必须有独立角色与任务证据。
