# Spec: role-profile-pages

**Objective.** Make “我的” useful and consistent without forcing twelve roles into identical empty settings pages.

**Pages.** MY personal page for each of the 12 roles.

**Requirements.** Keep a shared identity/account frame, then show only profile, permissions, earnings, schedule, membership, or account actions that the active role actually has. Hide unavailable features rather than render empty placeholders; when a feature is intentionally locked, explain why and provide the valid next step. Role switching is explicit and returns to the selected role’s home. Keep current financial values with period and unit; avoid unrelated work queue duplication if the main workspace already owns it.

**Acceptance.** All 12 roles are individually inspected and assigned a screen disposition; each has a correct role label, available actions, exit/switch path, and no unexplained empty region. Role switch never inherits another role’s object or navigation history.

**Reference trade-offs.** Use the simple account/navigation division from image 1/9; avoid social-profile elements or decorative avatar walls.
