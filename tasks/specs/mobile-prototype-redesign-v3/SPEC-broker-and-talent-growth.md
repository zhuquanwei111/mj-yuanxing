# Spec: broker-and-talent-growth

**Objective.** Organize recruiting, invitation, follow-up, activation, and retention into a clear, time-aware workflow for the agent/broker role.

**Pages.** P30, P30D, P31–P33; page count may change if distinct tasks merge or a missing task view is found.

**Requirements.** P30 defaults to the “today” follow-up queue, ordered by deadline/risk. A row connects streamer, reason, due time/status, and “记沟通”; long cards do not repeat multiple actions. Keep the user-mandated messages “回访第一：情绪、结业、激活三类今天必须碰” and “主播留存的第一道防线” visible as readable product guidance. Move only reviewer meta such as persona notes and design intent into the reviewer panel. P30D shows the selected person and current follow-up context, a chronological recent-contact timeline, and one main “记录本次沟通” action; save feeds back to the source row. P31 opens to a searchable lead pool; selecting a lead reveals the invitation content in readable paragraphs and a small, ordered set of outcomes. P32/P33 must distinguish current stage, blockers, owner, date and next action; duplicate funnel/overview information can be merged if a canonical destination remains.

**Acceptance.** An agent can find overdue and today items, record communication, review current invitation, move a lead to the appropriate next state, see feedback, and return to the same filtered queue. Full user-facing copy survives; reviewer-only small notes do not appear in the product. Names never wrap one Chinese character per line.

**Reference trade-offs.** Use image 6’s chronological record logic and image 5’s list-to-detail/primary-action hierarchy; reject emotional slider, recruiting hero art, and dense multi-button cards.
