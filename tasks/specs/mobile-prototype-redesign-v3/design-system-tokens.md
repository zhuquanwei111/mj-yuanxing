# 明镜原型共用视觉令牌与组件约定

本规范服务于主播、公会运营和平台管理的移动原型。默认画布与内容表面为白色；用清晰层级、细分隔和少量真实状态色表达信息，不用大面积铺色或装饰阴影。

## 颜色与文本

| 令牌 | 值 | 用途 |
|---|---|---|
| 中性色 0 / 50 / 100 / 300 / 600 / 900 | `#FFFFFF` / `#FAFAFA` / `#F2F2F2` / `#DEDEDE` / `#666666` / `#171717` | 白色表面、辅助背景、浅边界、分割线、辅助文字、标题/正文 |
| 主操作 | `#111111`，浅底 `#F2F2F2` | 页面主操作、选中与键盘焦点；不把主色当品牌装饰铺满页面 |
| 成功 | `#2F765F`，浅底 `#EEF6F1` | 已完成、直播中和正向结果；仅用于真实成功状态 |
| 提醒 | `#806216`，浅底 `#FAF6EA` | 需跟进状态 |
| 风险 | `#A33D3D`，浅底 `#FAF0F0` | 有风险/错误状态 |

标题 16px/600，区块标题 14px/600，正文 14px/400，辅助文字 12px/400。业务需要的欢迎标题、金额或指标可以放大，但必须保持数字单位、标题和说明的阅读关系。页面不使用紫色方向。

## 几何、密度与阴影

间距使用 4、8、12、16、24、32px 六级栅格。小标签、控件、卡片圆角依次使用 4、6、8px。卡片为白底、1px浅灰边框、无阴影；只有弹层或悬浮元素可用轻阴影。8px卡片间距是常用分组距离，不要求把普通记录包成卡片；普通任务、消息和名单使用行与分隔线。

密集运营页面允许在相邻字段使用 4px 或 8px 间距，长内容按自然阅读顺序换行；不通过缩小正文、裁掉类别名称或依赖横向拖动隐藏主要信息来塞入首屏。

## 操作与状态

- 主按钮用于当前页面最重要的提交、确认或推进动作；同一操作上下文通常只有一个。
- 次按钮用于可并列的次要操作；文字按钮用于查看、导航和列表辅助操作。无需把每个可点击项改成按钮外观。
- 所有操作保留清晰的默认、聚焦、按压和禁用反馈；桌面悬停只是补充。焦点环需可见，按压反馈短促，禁用态不误导为可操作。
- 风险用状态文字配色或圆点/图标表达，不用左侧彩色竖条；颜色不能取代“有风险”“待跟进”等文字。
- 全部页面与内部区域隐藏纵向、横向滚动条；原有触摸、滚轮、键盘和程序化滚动继续可用。单行筛选可横向滑动但不截断标签，并用边缘提示发现更多项目。
- 人物列表使用32px头像，个人详情使用64px头像；无本地素材时使用带浅灰边框的姓名首字占位，不生成虚构照片。
- 动画通常为150–200ms，并遵守 `prefers-reduced-motion`。

特殊页面若确有密度或状态差异，须按业务语义记录原因并限定作用范围；不为追求一致而改变流程或信息口径。
