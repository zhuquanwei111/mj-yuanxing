# Spec: streamer-workspace

**Objective.** Give the streamer a calm, direct “what do I do next?” experience for today, live plans, review, messages, profile, and activation.

**Pages.** P80–P85.

**Requirements.** P80 displays live status, one next task, checklist progress, and completion/return status; complete plan details route to P81 instead of appearing as a large collapsed block. P81 shows the current plan as a readable time sequence and provides an obvious return to today. P82 starts with one practical takeaway for tonight, then a compact set of result values; supporting data and historical evidence stay available without repeating P80/P81. P83 maintains conversation and business-object context, with an accessible fixed composer; quick questions appear only when useful. P84 separates identity/earnings summary from schedule, profile, and account actions; values include period and unit. P85 starts from the actual invite/binding state and presents only the next valid action, with membership details kept scannable.

**Acceptance.** Streamer completes the next task, sees confirmation/state update, opens the plan or review if needed, and returns without duplicate instructions or context loss. User must not need to expand “今晚完整安排” to discover a required action.

**Reference trade-offs.** Use image 6’s single-task check-in and time grouping, image 8’s schedule chronology, and simple labeled bottom navigation from images 1/9; do not copy their illustration, emotion widget, or dark theme.
