# 手机工作台设计基线 V2（V2-1 交付物）

日期：2026-10-09。依据 [信息架构规格 V2](spec-mobile-information-architecture-v2.md) 第 6 节要求，在改样式前形成本基线。
执行技能：`frontend-design`（领域方向与拒绝的默认布局）、`interface-design`（tokens、控件规格、状态）。

## 1. 产品领域与使用者

**领域（直播公会日常运营 / 主播行动）：** 班次（早班 7:30-16:30 / 晚班 16:30-01:30）、场次时段（20:00-23:00）、盯场、音浪与进场停留/进房率/曝光、三句话复盘、话术草稿→采纳→沉淀话术库、交接单与回执、带教第 N 天与结业评估、预警分级（有风险/待跟进）、排班与妆造预约。

**使用者与当下任务：**

| 使用者 | 何时打开 | 要完成的一件事 |
|---|---|---|
| 运营（小林） | 交班前后 5 分钟 | 按紧急度清掉今天的跟进队列 |
| 运营组长 | 班中 | 把总监下达、本组风险、分派回执推进一步 |
| 培训师（安姐） | 带教时段 | 知道今天带谁、谁要打分、谁临近结业 |
| 主播（小雨） | 开播前 | 看见唯一的下一步并做完 |

**应该是什么感觉：** 值班表般的紧致和安静——像一张排班表加一条待办队列，不像四张漂亮的数字卡。信息密度高但每条记录只讲一件事。

## 2. 设计方向

**签名元素：行动队列行（queue row）。** 把「对象 + 原因 + 时限/状态 + 一个动作」压成一行，状态用左侧 3px 色条而不是整块染色。每个工作台首屏只有一条主队列，其余内容降级为带名称的入口。

**Color world（来自直播间的颜色）：** 深夜直播间的暗与补光、场记板的黑白、监视器上跳动的数字、录制红点、数据曲线的青绿、预警红、值班表的表格线。

**颜色/文字/间距/密度 tokens：**

| 类别 | Token | 值 | 用途 |
|---|---|---|---|
| 表面 | `--bg` / `--card` | `#f7f8fa` / `#ffffff` | 屏幕底 / 记录面 |
| 文字 | `--ink` | `#111827` | 页面标题、关键数值 |
| 文字 | `--ink2` | `#4b5563` | 正文 |
| 文字 | `--ink3` | `#626c7b` | 元信息（白底 ≥4.5:1） |
| 结构 | `--line` / `--line2` | `#e5e7eb` / `#f1f2f5` | 分隔 / 极弱分隔 |
| 状态 | `--ok` | `#3F6212` | 已完成、达标 |
| 状态 | `--warn-ink` / `--warn-rail` | `#8a5a00` / `#D9A441` | 待跟进文字 / 色条 |
| 状态 | `--danger` | `#B91C1C` | 有风险、需补考 |

- **文字四级：** 页面标题 18px/650 · 区块标题 16px/650 · 正文 14px/400–500（行高 1.6）· 辅助 12px/400–500。关键数值 22–28px/650 + `tabular-nums`。不用字号表达层级的地方用字重与颜色补。
- **间距基线 4px：** 4 / 8 / 12 / 16 / 20 / 24 / 32。记录内 16，记录间 16，区块间 24。相关字段紧凑（8），独立任务区明显分组（24）。
- **密度：** workbench-tight。列表行 12px 纵向内边距；可点队列行高 ≥56px。
- **圆角：** 控件 10 · 记录 14 · 面板 18。
- **深度策略：只用边框**（borders-only），无阴影、无渐变；层级靠留白与色调差。
- **色彩配比：** 约 60/30/10——大面积中性底、白色记录面、~10% 状态色。颜色只表达状态，不做装饰。

## 3. 主要控件规格

| 控件 | 规格 |
|---|---|
| 主按钮 `.btn.p` | 高 44 · `#111827` 底白字 · 14px/600 · radius 10 · padding 0 16 |
| 次按钮 `.btn.g` | 高 44 · 白底 + 1px `--line` · `--ink` 字 · radius 10 |
| 危险按钮 `.btn.d` | 高 44 · 白底 + `--danger` 边 · `--danger` 字 |
| 分段视图 `.segview` | 高 44 · 容器 `--line2` 底 · 选中 `--ink` 底白字 · 每段带数量 |
| 视图页签 `.ptab` | 高 44 · 选中墨色下划线 2px + 字重 650 |
| 更多操作 | 行内「更多操作」按钮 → 手机视口内底部动作面板，行高 48、全宽、左对齐；主动作永不进面板 |
| 队列行 `.qrow` | 高 ≥56 · 左 3px 状态色条 · 主文案 14/500 · 原因 12 `--ink3` · 右侧 `›` |
| 排行记录 `.rankrow` | 序号 + 主标签 + 逐字段「标签/值」纵向对，不用横向滚动 |
| 条目状态 | 文字 + 形状（色条 / 点 / 徽章）双通道，不只靠颜色 |

**状态齐备：** 默认 / 按下（`scale(.97)`）/ 键盘焦点（2px 墨色描边 + 3px 偏移）/ 禁用（`opacity .55`）/ 处理中与已完成（toast + 就地状态翻转）。

## 5. 拒绝的默认布局及理由

| 拒绝的默认 | 换成 | 理由 |
|---|---|---|
| 四张等权 KPI 大卡开场 | 一条可下钻的概况条 + 主队列 | 四张同权卡会形成第二个焦点，抢在待办之前 |
| 所有内容切成同款圆角卡片（SaaS card kit） | 一条焦点记录 + 发丝线队列行 | 同款卡片让块与块之间没有主次 |
| `<details>` 折叠承担主要业务区 | 命名分段视图 + 数量提示 | 箭头折叠让主播动态、完整名单等关键区不可发现 |
| 宽表格横向滚动 / 微缩字号 | 纵向排行记录，逐字段带标签 | 目标宽度下横滑才能读完一条记录等于读不到 |
| 卡片里平铺多个同权按钮 | 一个主动作 + 更多操作（手机内动作面板） | 并排挤压内容，且分不清该点哪个 |
| 品牌渐变 hero、彩色图标砖 | 保持黑白中性，颜色只表达状态 | 装饰性颜色稀释了风险/完成色的语义 |

## 6. 逐页检查清单（实施时逐页执行）

按「用户当下任务 → 首要信息 → 主动作 → 次级入口 → 状态反馈」五问检查每一页；页面变体复用上述层级与控件规则，遇到真实差异再说明依据。
