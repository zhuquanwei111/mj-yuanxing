# 明镜原型 × 参考案例：页面结构复用映射

日期：2026-10-10  
范围：阶段二补充交付；覆盖参考图01/02/03/04/05/06/08/09及阶段一检索的 Dribbble 案例  
目标：说明现有原型中哪些页面可以直接采用参考作品的布局和组件关系，而不止借用配色。

## 复用口径

这里的“直接复用”是指可以沿用参考里的**版面骨架、信息分组、卡片结构、内容顺序和组件关系**，再用明镜现有的业务字段和文案填充。它不意味着原样移植课程/商品/招聘等业务内容、品牌素材或没有对应数据的指标；也不允许借此新增、删除或改变业务动作。参考屏如果包含明镜不存在的字段或控件，就只借用其布局关系。

复用等级：

- **直接照骨架：** 页面目标、信息关系和现有业务较接近，优先按参考屏的结构搭建。
- **同构适配：** 结构可照用，但需要按现有角色、数据、密度或移动端阅读方向调整。
- **只借局部：** 只复用一个组件/状态/反馈模式；不复用整页结构。

## 首批最值得直接落到标杆页的四组

1. **P10 / P11 / P01：** 先复用分步申请的页头进度、单步字段分组、底部前进/提交操作；表单步骤和校验规则原样保留。
2. **P21 / P31：** 复用招聘/CRM 的搜索、筛选和垂直对象卡结构；分别填主播与招募线索数据，保留现有筛选项和回访/邀约状态。
3. **P50 / P51 / P52：** 复用日历日期条、服务预约卡、时间/地点/要求/状态和完成回传的详情分区；这是参考图06和预约案例与原型业务最接近的一组。
4. **P70 / P71：** 直接复用参考图01/09订单卡“明细—金额—状态—单项操作”的排列，最适合把财务信息从散字段整理成移动端可扫读卡片；金额来源和确认业务规则不动。

第二批再把图08的通知分组用于P92，把图03/04的任务进度卡用于P40/P41/P42，把社媒任务管理案例用于P25/P60/P61/P62。**P20、P30**虽然能用CRM首页结构，但当前优先级队列已经按业务目标设计，应复用卡片、筛选和对象详情衔接，不要把参考首页里的搜索/推荐区机械放到首屏最前。

## 复用时必须保留的原型元素

- 原有页面目标、对象关系、业务字段、权限范围、路由和流程步骤。
- 原有按钮文案/动作、状态迁移、确认规则、表单验证及结果反馈。
- 真实存在的日期、金额、人数、进度和状态；不填入参考作品中的虚构数字或统计口径。
- 需要横向展示的内容优先压成手机可读的卡片/标签行；不得照搬海报式斜屏拼贴作为真实操作页面。

## 推荐实施顺序

**先试装结构相似且能验证复用的 P10/P11、P21/P31、P50/P51、P70/P71；再覆盖 P20/P22/P25、P40–P42、P60–P62、P90/P92 和角色 MY。** 每批先列改前页面的控件与业务动作，再套参考结构，最后逐动作回归。组件结构相同可以复用模板；业务对象和权限不同仍保留页面差异。
